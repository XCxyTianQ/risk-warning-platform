| 项目 | 内容 |

---

## 1. 模块定位

风险评分回答"这家企业风险高不高"，金融分析模块回答**"为什么"**：把财报从"几个字段"变成可计算、可对标、可解释的分析结论。

它不是再做一个查询页，而是补上三类能力：

| 能力 | 说明 |
|---|---|
| **计算** | 从原始财报科目推导比率、增速、周转、现金含量等派生指标，口径统一在服务层 |
| **建模** | 引入三个经典财务预警模型（Altman Z/Z''、Piotroski F、Beneish M），输出分数、区间与输入完整度 |
| **对标** | 同行业分位数定位，回答"这个毛利率在同行里是高还是低" |

设计原则与平台一致：**缺失即不参与**（算不出的指标标注原因，不猜测）、**口径可追溯**（每个指标标注来源与年份）、**模型披露输入**（逐项标注 exact / approx / missing）。

## 2. 数据层

### 2.1 存储结构

`finance` 表在原 5 个字段（营收、净利、资产负债率、总资产、总负债）基础上新增 `metrics_json`：

```json
{
  "revenue_wan": 525221.51, "net_profit_wan": 1032.8, "deducted_profit_wan": -29416.31,
  "gross_margin": 19.975, "net_margin": 0.1966, "roe": 0.1392, "debt_ratio": 44.59,
  "current_ratio": 1.2631, "asset_turnover": 0.3973, "ocf_wan": 11134.66,
  "current_assets_wan": 2087369.4, "current_liabilities_wan": 1652483.2,
  "accounts_receivable_wan": 228502.1, "inventory_wan": 292818.6,
  "surplus_reserve_wan": 133692.4, "undistributed_profit_wan": -22598431.7,
  "operating_profit_wan": 4774.3, "finance_expense_wan": 6321.5, "...": "..."
}
```

- 单位约定：绝对科目为**万元**，比率类为**百分比原值**，倍数类为**原值**；
- 键名后缀即单位（`_wan` / `_ratio` 由 METRIC_META 统一管理）；
- 老库通过 `init_db()` 中的轻量迁移自动补列（SQLite `ALTER TABLE ADD COLUMN`，幂等）。

### 2.2 双信源字段级合并

`finance` 维度由"降级链"改为"合并"：

| 信源 | 提供内容 |
|---|---|
| 东财 `stock_financial_abstract` | 80 项比率/每股指标（毛利率、ROE、周转率、现金含量…） |
| 新浪 `stock_financial_report_sina` | 三表绝对值科目（流动资产/负债、应收账款、存货、固定资产、累计折旧、盈余公积、未分配利润、营业利润、财务费用…） |

合并键为 `(企业, 年份, 报告类型)`：`metrics_json` 做字典合并，顶层字段"非零值才覆盖"，来源串拼接保留两段。任一方缺失时，另一方的贡献不受影响；两方都失败才标记 `data_status=error`。

> 东财比率不足以算 Z/F/M 模型（缺绝对值），新浪三表没有现成比率——两者合并后才构成完整输入集。

## 3. 计算层（`app/services/finance.py`）

### 3.1 概览 KPI

16 项：营收、归母净利润、扣非净利润、毛利率、净利率、ROE、ROA、资产负债率、经营现金流、现金含量、营收增速、净利增速、流动比率、应收账款周转天数、存货周转天数、商誉/净资产。

每项返回 `value / prev / yoy / trend`。`trend` 表达"方向好坏"（结合 `higher_better`），而非单纯的数值升降——资产负债率下降是好事，显示为向好。

### 3.2 趋势序列

按六组输出给前端：规模、盈利能力、偿债与杠杆、营运效率、现金流质量、成长性。每组为 `{key, label, unit, points[{year, value}]}`，前端据此通用渲染折线/柱线图。

### 3.3 杜邦分解

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
```

逐期给出三因素水平值，并对最近两期做**顺序归因**（贡献之和 = ROE 变动，单位百分点）：

```
ΔROE_margin   = (m₁ − m₀) × t₀ × l₀
ΔROE_turnover = m₁ × (t₁ − t₀) × l₀
ΔROE_leverage = m₁ × t₁ × (l₁ − l₀)
```

### 3.4 财务预警模型

| 模型 | 公式 | 阈值 | 输入来源 |
|---|---|---|---|
| **Altman Z** | 1.2X₁+1.4X₂+3.3X₃+0.6X₄+1.0X₅ | >2.99 安全 / 1.81~2.99 灰色 / <1.81 困境 | X₁营运资金/总资产、X₂留存收益/总资产、X₃EBIT/总资产、X₄市值/总负债、X₅营收/总资产 |
| **Altman Z''** | 6.56X₁+3.26X₂+6.72X₃+1.05X₄ | >2.6 安全 / 1.1~2.6 灰色 / <1.1 困境 | 同上，X₄改为**账面净资产/总负债**（非制造业/新兴市场口径） |
| **Piotroski F** | 9 项信号各 1 分 | ≥7 强 / 4~6 中 / ≤3 弱 | ROA、经营现金流、ΔROA、应计质量、Δ杠杆、Δ流动比率、股本、Δ毛利率、Δ周转率 |
| **Beneish M** | −4.84+0.92·DSRI+0.528·GMI+0.404·AQI+0.892·SGI+0.115·DEPI−0.172·SGAI+4.679·TATA−0.327·LVGI | > −1.78 提示盈余操纵嫌疑 | 应收账款/毛利率/资产质量/销售增长/折旧率/费用率/杠杆/总应计 |

实现要点：

- **EBIT** = 营业利润 + 财务费用（财务费用为支出项，加回即为息税前利润）；
- **留存收益** = 盈余公积 + 未分配利润；
- **市值**：`stock_zh_a_spot_em` 全市场快照，带 30 分钟缓存（成功与失败都缓存）与 2.5 秒超时；取不到时 Z 标注"不可计算"，Z'' 照常输出；
- **DEPI 为近似项**：新浪现金流量表不含折旧附注，当期折旧用"累计折旧增额"近似，上期按累计折旧 10% 近似，返回时明确标注 `approx`；
- **F-Score 附加提示**：当 ROA < 2% 时提示"F-Score 衡量同比改善方向，不衡量绝对盈利水平"，避免"低盈利高得分"被误读。

### 3.5 同业对标

取同行业企业（不足 2 家时补充全库企业并在 `note` 中说明），计算 9 项指标的分位数。除资产负债率外均为"越大越好"，分位数统一为"位置越好分位越高"。

### 3.6 异常勾稽（10 条规则）

| 代码 | 触发条件 | 等级 |
|---|---|---|
| `OCF_NEGATIVE` | 净利润 > 0 且经营现金流 < 0 | 高 |
| `LOW_CASH_CONTENT` | 经营现金流/净利润 ∈ [0, 0.5) | 中 |
| `AR_DIVERGENCE` | 营收增速 > 20% 且应收增速 > 营收增速 + 20pct | 高 |
| `MARGIN_ABOVE_PEERS` | 毛利率高于同业中位数 20pct 以上 | 中 |
| `DEBT_JUMP` | 资产负债率同比上升 ≥ 10pct | 高 |
| `INVENTORY_WORSEN` | 存货周转天数连续两期上升且累计 > 30% | 中 |
| `GOODWILL_HEAVY` | 商誉/净资产 > 30% | 高 |
| `LOW_DEDUCTED` | 扣非净利润/净利润 < 0.5（为负时单独措辞） | 中 |
| `GROWTH_SCISSOR` | 净利增速 − 营收增速 > 50pct 且营收正增长 | 中 |
| `AR_WORSEN` | 应收账款周转天数连续两期上升且累计 > 30% | 中 |

每条异常返回标题、具体数字、证据对象与等级，按高→中→低排序。

## 4. 接口

### 4.1 REST API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/finance/overview` | 全库财务概览（选择器与横向筛选） |
| GET | `/api/finance/{id}/analysis?years=5&peers=true` | 完整分析结果 |
| GET | `/api/finance/{id}/report?years=5` | 确定性 Markdown 报告 |

### 4.2 Agent 工具

| 工具 | 用途 |
|---|---|
| `get_financial_analysis` | 一次取全 KPI / 杜邦 / 三模型 / 同业 / 异常 |
| `compare_financials` | 2~5 家企业财务横向对比 |
| `screen_by_financial_metric` | 按指标筛选（如"毛利率低于 20%"） |

内置技能「财务分析」规定了取数顺序与报告结构（结论摘要 → 盈利与成长 → 杜邦 → 模型 → 异常 → 同业 → 数据说明），内置预设「财务分析师」按白名单收敛工具与技能。

### 4.3 前端面板

`web/src/views/FinanceView.vue`，在左侧功能栏（📈）与命令面板中打开，可停靠/最大化：

企业选择器 + 年份切换 + 刷新 + 导出报告 → KPI 卡片 → 六张趋势图 → 杜邦表与归因条 → 四张模型卡 → 异常列表 → 同业雷达与对标表 → 数据说明。

Agent 调用金融工具后，工作区自动开窗并定位到对应企业（`workspace/store.ts:openForTool`）。

## 5. 验证记录

真实数据（2021–2025 五期年报，东财 + 新浪合并）：

| 企业 | 营收（万元） | ROE | Z'' | F | M | 异常 |
|---|---|---|---|---|---|---|
| 贵州茅台 | 17,205,417 | 33.65% | 安全区 | — | — | — |
| 宁德时代 | 42,370,183 | 21.42% | 3.407 安全区 | 6/9 | −2.714 | 0 |
| 三一重工 | 8,969,951 | 9.52% | 4.666 安全区 | 8/9 | −2.831 | 0 |
| 康美药业 | 525,222 | 0.14% | **−3.991 困境区** | 9/9 | −2.552 | 扣非占比偏低 |

康美药业的组合结论具有代表性：**Z'' 落在困境区**（留存收益为巨额负数）、**F-Score 9/9**（同比改善方向）、**扣非净利润为负**（盈利依赖非经常性损益）——三者并不矛盾，分别刻画"存量财务结构""同比改善方向""利润质量"，模块在输出时对每项都给出了口径说明。

端到端验证：对话"康美药业最新财报的盈利质量怎么样" → Agent 自动调用 `search_enterprise` → `get_financial_analysis`，回答中引用了模型分数、阈值与异常信号（`tests/_chat_finance.txt`）。

## 6. 已知限制

1. 市值接口（`stock_zh_a_spot_em`）在本机网络环境不可用，**Altman Z 通常不可计算**，以 Z''（账面口径）为主；
2. DEPI 为近似项，Beneish M 结论需结合审计意见；
3. 同业对标依赖企业行业标注，样例数据部分行业为"上市公司"等宽口径，已在对标说明中提示；
4. 非上市企业无公开财报，模块如实返回"无财务数据"，需人工导入；
5. 报告为确定性 Markdown，叙述性解读由 Agent 完成（数字全部来自引擎，模型只负责组织语言）。
