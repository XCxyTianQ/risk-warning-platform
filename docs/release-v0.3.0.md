# 企业经营风险预警平台 · 桌面端 v0.3.0（Windows x64）

基于多模态大模型的企业经营风险预警平台 —— 首个 Windows 桌面端发行版。
内置 Python 后端与前端，**双击即用，无需安装 Python/Node**。

## 首次使用

1. 双击运行（未签名，SmartScreen 提示时选「更多信息 → 仍要运行」）；
2. 首次启动会自动初始化数据库并**灌入样例企业数据**（茅台/宁德/獐子岛/康美/深度求索等）；
3. 点右上角 **⚙ 设置 → 模型服务**：选择提供商（DeepSeek 等）→ 填自己的 API Key → 「获取可用模型」→ 保存；
4. 回到主界面用自然语言提问，例如：`康美药业现在风险怎么样？`

## 功能一览（v0.3.0）

- **对话式研判**：SSE 流式回答 + 工具调用实时展示 + 动作工具二次授权
- **六维评分画像**：财务健康 / 法律合规 / 舆情声誉 / 经营能力 / 信用状况 / 供应链稳定 + AAA~C 评级
- **数据源**：AkShare 多信源（东方财富 / 新浪 / 巨潮），支持自由添加企业、一键刷新
- **预警中心**：评分自动生成工单 → 处置流转（待处理/处理中/已处置/忽略）→ 处理流水 → Markdown 报告导出
- **成本控制**：对话压缩（前缀缓存复用）、缓存命中率与用量常驻状态栏、提示词缓存预热
- **生态能力**：MCP 双向接入、技能库、Agent 预设 + 手搓 HTTP 插件、JSON 导入导出
- **对话管理**：搜索/置顶/重命名/清空、导出 MD+JSON、只读分享链接
- **桌面端**：IDE 式多面板停靠工作区、托盘/菜单、单实例、动态端口、数据落 `%APPDATA%\RiskWarningPlatform\`

## 数据与隐私

- 数据目录：`%APPDATA%\RiskWarningPlatform\data\`（删除该目录即可重置）
- 日志：`%APPDATA%\RiskWarningPlatform\logs\backend.log`（应用菜单「文件 → 打开日志」）
- API Key 仅保存在**本机**（设置面板填写），不上传任何服务器
- 企业数据来自公开信源（东方财富 / 新浪财经 / 巨潮资讯等），不构成投资建议
