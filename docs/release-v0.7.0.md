# v0.7.0 · 通用表格工作簿（空白表格 + 多工作表 + 数据透视表 + 宏）

> 发布日期：2026-09-12　｜　适用：Windows 10/11、macOS 11+（Apple Silicon / Intel）
>
> 回应队友反馈：**很多表格不会是标准模板格式**。这一版把表格从"模板表"改成**通用工作簿**——
> 新建就是一张空白网格，列标题、行标题自己填；并补上多工作表、数据透视表与宏。
> 覆盖安装即可，历史表格**自动升级**（旧的单表结构会归一化成一个工作表，数据与映射都保留）。

---

## 一、空白表格：不再要求你先选模板

- 「新建表格」默认给 **空白表格**：8 行 × 4 列空网格，**列标题与行标题全部留空**
- 表头直接改列名（如 `科目`、`2025`、`备注`、`合计`），期间可留空——填了才参与入库与同比
- 行标题同样直接改；模板（利润表/资产负债表/现金流量表/关键指标表）降级为「起始内容」里的可选项

## 二、多工作表（工作簿）

- 底部**工作表页签**：`＋` 新建、`✎` 重命名、`🗑` 删除、点击切换
- 每张工作表有独立的行列数据与科目映射；表格列表显示工作表数量
- **入库、勾稽校验、识图填表都以当前工作表为准**
- 旧数据兼容：升级前的单表记录读入时自动变成「Sheet1」，列/行/映射完整保留

## 三、数据透视表

- 工具栏「⊞ 透视表」：把当前工作表当数据表，选 **行字段 / 列字段 / 值字段 + 聚合**（求和·计数·平均·最大·最小）
- 实时预览矩阵与合计，并提示扫描行数、无法解析的数值
- 一键 **插入为新工作表**——长表（`年度 | 科目 | 数值`）秒变「科目 × 年度」矩阵
- 数值容错：千分位、百分号、括号负数都能识别

## 四、宏

- 工具栏「⚙ 宏」：左侧宏列表（内置 + 我的），右侧代码编辑器，运行日志与错误提示
- **内置 6 个常用宏**：按行求和（新增「合计」列）、单位换算（元 → 万元）、删除空行、
  重算资产负债率、纵向汇总（追加合计行）、按列取整
- 宏里可用：`sheet.columns` / `sheet.rows`、`num()`、`cell(行,列)`、`set(行,列,值)`、
  `addColumn()` / `addRow()`、`colValues()`、`log()`
- 运行前自动记录快照，**Ctrl+Z 可撤销**；宏可「保存到表格」随表存储
- **边界说明**：这是脚本宏（JS），不是 Excel VBA——不支持 VBA 语法，也不做宏录制

## 七、已知边界

- 公式仍在前端计算（结果随表落库）；暂不支持数组公式、条件格式、图表与跨表引用；
- 透视表按"当前工作表即数据表"建模，暂不支持多重值字段与计算字段；
- 宏为 JS 脚本，无 VBA 兼容、无录制；
- `Altman Z`（市值口径）仍缺市值数据源，报告写"不可计算"，以 `Z''` 为准。

> 数据来自公开信源，模型结果为规则化测算，不构成投资建议。
