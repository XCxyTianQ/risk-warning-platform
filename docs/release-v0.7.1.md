# v0.7.1 · 表格编辑手感修复 + 工作区放大（长表导入可选不透视）

> 发布日期：2026-09-12　｜　适用：Windows 10/11、macOS 11+（Apple Silicon / Intel）
>
> 回应队友实测反馈：**双击进不去编辑、表格工作区太小**。这一版把表格编辑的交互修好，
> 并把表格工作区从"挤在右下角"改成"铺满窗口"，另外把长表导入做成可选（原样保留，自己透视）。
> 覆盖安装即可，历史表格与数据不受影响。

---

## 一、单元格编辑修好了（三个真实原因）

| 问题 | 原因 | 现状 |
|---|---|---|
| 双击后光标一闪就没 | 编辑框里的点击冒泡到单元格，触发了"提交并关闭" | 编辑框内部点击不再关闭编辑器 |
| 回车提交后又跳到下一行编辑 | 回车事件在编辑框处理完还冒泡到表格，等于"提交 + 立刻编辑下一行" | 编辑框内的按键只由编辑框处理，回车只提交（下移一格但不进编辑） |
| 直接打字只留下最后一个字 | 进入编辑时全选了原内容，第二个按键把第一个字替换掉 | 打字进入编辑时光标在末尾（输入 123 就是 123）；双击/F2 仍全选便于覆盖 |

其它手感改进：

- **点击已选中的单元格也能进编辑**（不必非双击）；但拖拽扩选不会误触编辑（实测拖选 6 格不弹编辑器）
- Esc 退出编辑、Enter 下移、Tab 右移、Delete 清空、Ctrl+Z/Y 撤销重做保持原样

## 二、表格工作区放大了

- 表格面板打开即**铺满窗口**；点右上「还原 ✕」回到右侧停靠态，**编辑状态不丢**（同一个组件实例，只换外框大小）
- 面板上方固定区做紧凑化：标题与徽标一行、企业/单位/口径一行、校验横幅默认折叠（「展开详情 ▾」再看）
- 工具栏此前**没有任何样式**，窄面板会折成好几排——现在固定单行、放不下就横向滚动，ƒx 公式栏自适应宽度
- 实测（窗口 1426×849）：表格区 **262px 高 → 443px 高 × 1359px 宽**；停靠态也有 343px 高

## 三、长表导入：可选"原样保留"

- 「导入文件 / 粘贴」对话框新增开关：**长表原样导入（不自动透视）**
- 勾上后 `年度 | 科目 | 数值` 这类长表整张照原样进来（不做自动透视），再用工具栏「⊞ 透视表」自己挑
  **行字段 / 列字段 / 值字段 + 聚合**（求和·计数·平均·最大·最小），预览后「插入为新工作表」
- 不勾则维持原行为：能识别的长表自动透成「科目 × 年度」矩阵
- API：`POST /api/tables/import` 新增 `keep_long`（默认 `false`），老调用不受影响

## 六、已知边界（与 v0.7.0 相同）

- 公式仍在前端计算（结果随表落库）；暂不支持数组公式、条件格式、图表与跨表引用；
- 透视表按"当前工作表即数据表"建模，暂不支持多重值字段与计算字段；
- 宏为 JS 脚本（不是 VBA），无录制功能；
- `Altman Z`（市值口径）仍缺市值数据源，报告写"不可计算"，以 `Z''` 为准。

> 数据来自公开信源，模型结果为规则化测算，不构成投资建议。
