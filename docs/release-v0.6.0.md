# v0.6.0 · 表格工作区与多模态输入（Excel 式编辑 + 贴图读数）

> 发布日期：2026-09-12　｜　适用：Windows 10/11、macOS 11+（Apple Silicon / Intel）
>
> 这一版补齐了**两类输入能力**：把「表格」做成平台里可在线创建、在线编辑、可入库测算的一等对象；
> 让对话区能直接**贴图 / 传文件**，模型读图后把数字填进表格。
> 覆盖安装即可，数据目录与历史数据不变。

---

## 一、表格：从"上传文件"升级为在线表格工作区

### 侧边栏入口

左侧功能栏新增 🧾 **财报表格**（带数量角标）。点开即见**已上传与已创建的表格**列表，
也可以直接新建（4 套模板：利润表 / 资产负债表 / 现金流量表 / 关键指标表），或导入文件、粘贴建表。

### 在线编辑（Excel 式）

| 能力 | 说明 |
|---|---|
| 单元格编辑 | 双击或直接输入；Enter 向下、Tab 向右、Esc 取消 |
| **公式** | `=B5/B4*100`、`=SUM(B2:B5)` —— 支持算术/比较/括号/单元格引用/区域/文本连接，30+ 函数（SUM、AVERAGE、IF、ROUND、SQRT、MEDIAN…）；公式单元格带 ƒ 角标，循环引用与除零等给出 Excel 风格错误值 |
| 区域选择 | 拖拽框选、Shift+点击扩选、Ctrl+A 全选、点行列头选整行整列 |
| 复制粘贴 | Ctrl+C/X/V 与**系统剪贴板 TSV 互通**——可以直接从 Excel 复制一块粘进来，也可以复制出去 |
| 填充 | Ctrl+D 向下、Ctrl+R 向右（含公式） |
| 行列操作 | 选区插入/删除行、删除列、新增期间列；点列头 ▲▼ 按该列升/降序排序 |
| 数字格式 | 千分位 / 整数 / 百分比 / 常规，一键应用 |
| 撤销重做 | 各 30 步（工具栏 ↶ ↷ 或 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y） |
| 编辑栏 | 显示当前单元格地址与公式，可直接输入公式应用到当前单元格 |

### 三条读取入口，汇入同一张表

1. **图片 / 截图** → 视觉模型识别成结构化字段，**自动填入对应科目**
2. **CSV / XLSX / XLS** → 服务端确定性解析（宽表「列=期间」与长表「年度/科目/数值」自动识别并透视，表头里的「单位：万元」「合并报表」自动带入）
3. **粘贴 TSV** → 从 Excel 复制整块，一步建表

### 入库前先过勾稽校验

资产 = 负债 + 所有者权益、资产负债率与负债/资产一致性、取值域、缺科目提示……
**校验不通过直接阻止入库**；图片识别的数字默认「待确认」（黄色角标），确认后才允许入库——
平台对"数据"也做风险控制。入库后数据带「用户提供」溯源，参与六维评分与金融分析
（没有公开财报的企业，现在也能被测算），默认不覆盖公开信源数据，冲突逐期列出差异。

## 二、多模态输入：对话里直接贴图/传文件

- 输入框旁新增 **＋** 按钮：图片/截图、Excel/CSV、任意文件三种入口；**粘贴截图**（Ctrl+V）与拖拽同样可用
- 图片在前端先压缩（长边 ≤1600）再上传，附件按内容哈希去重、落盘保存，消息里显示缩略图
- 模型会**自己决定**是否读图（`read_attachment` 工具），返回结构化结果（科目 / 数值 / 映射 / 置信度 / 不确定点）
- **当期多模态、历史文本化**：只有最新一轮把图片发给模型，之后自动换成识别结果的文字摘要——
  省 token，也避免历史图片导致的端点兼容问题

## 五、已知边界

- 公式在**前端**计算（结果随表格落库，后端只读数值）：暂不支持数组公式、跨表引用、条件格式与图表；
- 数据透视表、宏、多工作表（一个文件多个 sheet 目前只读第一个）尚未支持；
- 图片识别的准确率取决于模型，财报数字请务必核对后再确认入库（系统默认要求确认）；
- `Altman Z`（市值口径）仍缺市值数据源，报告会写"不可计算"，以 `Z''` 为准。
