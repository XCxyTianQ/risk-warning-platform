口径：为什么闭卷不等于纯记忆

部分题可凭通用金融常识推导，且闭卷提示词鼓励"未陈述则推导"，因此闭卷得分是记忆污染的上界估计。 而"闭卷下写出与标准答案一致的数值"这一项不依赖提示词风格，是更硬的证据。

判分

BFCL 判分是官方 checker 的自实现移植；OmniDocBench 四项是自实现保真度指标，不是官方 TEDS/CDM，不得与官方榜单直接等同。

样本与未做

FinanceBench 用开源子集 150 题；闭卷对照只在这一组题上做过，结论仍需换一个未被污染的基准复验。 T6 Agent 工具链未纳入自建基准；长稳测试（8 小时 / 2000 请求）未做。

产品链路的一条硬约束

平台后端附件目前只接受图片，不支持 PDF：同一张图在聚合网关路由下返回 HTTP 400，官方直连正常，因此视觉对比里我方必须走官方直连。PDF 抽取与检索在评测侧完成， 产品化需要补后端的 PDF 能力。

成本口径

我们按官方 peak 价计（cache-hit $0.006 / cache-miss $0.30 / 输出 $1.20 每百万 token）， 实际可能更低；Luna 与 GLM-5.3-Flash 网关未公布价目，只记 token 不估钱。
